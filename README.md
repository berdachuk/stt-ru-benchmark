# Русский STT: Whisper на своих GPU против Deepgram

Открытый замер точности распознавания русской речи. Шесть движков, один и тот же
набор файлов, одна и та же нормализация текста, воспроизводимый код.

Повод простой: **публичных цифр WER по русскому языку у Deepgram нет** — ни в
документации, ни в маркетинге. Есть общий показатель 5.26 % (англоцентричный) и
заявление «мы лучше Whisper на 7 языках из 7» без раскладки. Поэтому мы измерили
сами.

*English summary: an open WER/CER benchmark of Russian speech recognition —
self-hosted Whisper large-v3 vs Deepgram Nova-2/Nova-3 on FLEURS-ru, identical
audio and identical text normalization for every engine. Harness and raw results
are in this repo.*

## Результаты

**FLEURS-ru (test), первые 150 сэмплов, 28.4 минуты аудио. Ноль ошибок вызова у всех движков.**

| движок | WER | CER | медиана задержки | RTF |
|---|---:|---:|---:|---:|
| **Deepgram nova-2** | **3.67 %** | 1.12 % | 1.85 с | 0.223 |
| **Whisper large-v3** (свои GPU, прямой вызов) | **3.74 %** | **1.02 %** | **1.18 с** | **0.11** |
| **WhisperX-пайплайн** (VAD + выравнивание, свои GPU) | 3.74 % | 1.02 % | 3.79 с | 0.348 |
| Whisper-turbo, RU файн-тюн — *после починки дефекта* | 4.36 % | — | 1.43 с | 0.133 |
| **Deepgram nova-3** (флагман) | 6.51 % | **4.42 %** | 1.83 с | 0.171 |
| Whisper-turbo, RU файн-тюн — как есть | 8.65 % | 1.80 % | 1.43 с | 0.133 |

`RTF` (real-time factor) — доля реального времени на обработку: 0.11 значит, что
минута аудио распознаётся за 6.6 секунды. Меньше — лучше.

### Три вывода

**1. Self-hosted Whisper не проигрывает коммерческому API.** Разница с лучшей
моделью Deepgram — 0.07 процентного пункта, на 150 сэмплах это статистический
ноль. По символам Whisper даже точнее (1.02 % против 1.12 %) и при этом **вдвое
быстрее** по RTF.

**2. Флагман Deepgram на русском хуже их же предыдущей модели.** Nova-3 — 6.51 %,
Nova-2 — 3.67 %. Разница почти двукратная, и она устойчива по всей выборке
(промежуточные значения на 50/100/150 сэмплах не сходились). Настораживает
соотношение метрик: у Nova-3 CER 4.42 % при WER 6.51 %, тогда как у всех
остальных движков CER ниже WER в 3–4 раза. Такой почерк характерен не для
«плохо расслышал», а для другого формата записи (цифры вместо слов, латиница).

**3. Метрика может измерять баг, а не качество.** RU-файн-тюн Whisper-turbo
показал 8.65 % — вдвое хуже ванильного large-v3. Разбор расхождений показал, что
модель **вставляет пробел внутрь слова** при декодировании:

```
телевизион ные · обнаруж ены · передав аться · выб орочно · прив ести
```

Речь распознана верно, слово разорвано. Для WER это двойной штраф — и замена, и
вставка. Дефект встретился **62 раза на 52 из 150 сэмплов** (35 % записей), тогда
как у large-v3 — один раз. После склейки разорванных слов WER падает с 8.65 % до
**4.36 %**, то есть модель сопоставима с остальными.

Мораль общая: прежде чем делать вывод «модель хуже», посмотрите на сами
расхождения. Половина разрыва здесь была дефектом постобработки.

## Как воспроизвести

```bash
pip install -r requirements.txt

# свои модели через OpenAI-совместимый API
K=<ключ> python harness/stt_bench.py --limit 150

# Deepgram nova-3 и nova-2
DG=<ключ deepgram> LIMIT=150 python harness/dg_bench.py

# WhisperX-пайплайн (upload → poll → текст)
SC=<токен> LIMIT=150 python harness/sc_bench.py

# разбор: сколько WER съедает дефект разрыва слов
K=<ключ> LIMIT=150 python harness/stt_split_bug.py
```

Сырые результаты — в [`results/`](results/).

## Методика

- **Набор**: [`google/fleurs`](https://huggingface.co/datasets/google/fleurs),
  конфигурация `ru_ru`, сплит `test`, первые 150 сэмплов по порядку (без отбора).
- **Аудио**: файлы отправляются **байт в байт** как есть, без пересжатия и
  ресемплинга — все движки слышат один и тот же сигнал.
- **Нормализация** (одинаковая для всех, включая эталон): нижний регистр, `ё→е`,
  снятие пунктуации, схлопывание пробелов. Без неё сравнивались бы правила
  оформления, а не распознавание.
- **Метрики**: `jiwer` — WER по словам, CER по символам.
- **Задержка**: полное время запроса со стороны клиента, вместе с сетью и
  очередью, а не время инференса.

### Чего этот замер НЕ показывает

**FLEURS — чистая студийная начитка новостных фраз.** Это лёгкий материал:
один диктор, без шума, без перебивок, без спонтанной речи. Реальные созвоны,
диктофонные записи и телефон дадут заметно худшие цифры у всех движков — в
литературе для русского телефонного аудио WER доходит до 35 %.

Поэтому цифры отсюда **нельзя** сравнивать с чужими бенчмарками на других
наборах: например, ставить наши 3.74 % против заявленных Deepgram 5.26 % было бы
подтасовкой — это разные наборы и разная сложность. Ценность этой таблицы только
в том, что все шесть строк получены **на одинаковом материале**.

Следующий шаг — прогон на [Golos](https://www.openslr.org/114/) (краудсорс и
дальнее поле) и Common Voice ru, где слышна реальная речь, а не диктор.

## Точки отсчёта из литературы

| источник | WER |
|---|---|
| Whisper v3 на Common Voice 17.0 ru | 9.84 % |
| его RU файн-тюн (`antony66/whisper-large-v3-russian`) там же | 6.39 % |
| Deepgram Nova-3, общий batch (англоцентричный) | 5.26 % |
| независимые замеры Nova-3 в реальных условиях | 7–10 % |
| OpenSTT: телефон / YouTube / книги | 34.8 / 19.1 / 18.1 % |
